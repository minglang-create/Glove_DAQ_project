# 简化启动方案(2026-09-04 定稿, 分支 cam-xvs-simple-start)

> ★2026-09-04 实测通过★ 全链路同时跑: 手套 60Hz 零错 + 双摄 60fps(dpts -5~-6µs)
> + 对齐引擎锁定(offset=-3.90ms, σ=173µs, n>1000)。

> 取代《协议契约_V1 第四次修订》中的启动流程部分(§6 XVS 线、§7 全流程);
> 事务模型、小包表、数据帧布局、CRC 等其余部分**不变**。

## 为什么改

实验 B(2026-09-04)实锤:**IMX415 从机启动必须同时收到 XVS+XHS**,而 V4 板的
XHS 网只在两颗相机间互连、没接 STM32 → "STM32 供 XVS 驱动双从相机"此板走不通。
解法 = XVS 源移回相机:**cam0 当主机自产 XVS+XHS**(本手套内 cam1 直接锁,
V2/V3 已验证 dpts 恒 −6µs),**STM32 从"发 XVS"改为"捕获 XVS"**——
TXS0101 双向电平转换自动转向,硬件一根线不用动。

顺带把主从分配砍到最简:**主机不等从机、不设应答窗**;主/从机是否都在工作,
由工人根据两只手套的 LED 灯光自行判断。

## 新启动流程

```
双方上电 → 各自自检(RV: 相机在位+SD; STM32: CAN/IMU) → RV 发 0x5501
  → STM32 自检完 + 收到 0x5501 → LED 亮(等按键)
工人按【任一只】手套按键(全流程唯一一次按键)
  → 该侧 RV 发 0x5101"是主机"
  → 该侧 STM32: ①拉低 XVS 50ms(向对侧手套宣告"我是主机")→ 释放
               ②PB10 切 TIM2_CH3 输入捕获(下降沿, 从此只听不说)
               ③发 0xC301"请求采集"(P0=1)给自己的 RV
  → RV 收 0xC301 → 启动相机(hwsync: cam1 从机先武装, cam0 主机后起振,
     ★cam0 起振即向全系统持续输出 XVS+XHS★) → 回 0xC101
  → STM32 捕获到第一个 XVS 下降沿 = CYCLE 1 → 逐拍采集/装数据帧/拉 PA1
  → RV 读到第一个数据帧 = RUNNING(开录像段)
对侧手套(从机, 无按键): STM32 检测 XVS 持续低 >30ms(运行中低脉宽仅 7.2µs,
  不会误判)→ 自判从机 → 装 0x5201 → 发 0xC301(P0=2)给自己的 RV → …
  ⚠ 双手场景本分支未闭环(见"已知边界")
暂停/恢复: 各手套自己按键 → 0xC201/0xC101(XVS 不停, 相机不失锁)
重新自检: 0x5F01(此时才停相机/XVS)
```

## 关键参数变化

| 项 | 旧(STM32 供 XVS) | 新(cam0 供 XVS) |
|---|---|---|
| XVS 源 | STM32 PB10 定时器输出 | cam0(IMX415 internal master) |
| XVS 频率 | 60.000Hz(晶振) | **60.03Hz**(= VMAX 2300 × 1H 7.242µs = 16.658ms) |
| XVS 低脉宽 | 7.25µs | 7.242µs(1H, XVSLNG=0) |
| STM32 PB10 | TIM2_CH3 输出 | 宣告期短暂输出(拉低50ms), 之后**输入捕获** |
| XHS | 无(死因) | cam0 自产, 相机间板上互连(138kHz, 1H) |
| 主从宣告 | 拉低 300ms + 500ms 等从机窗 | **拉低 50ms, 不等从机** |
| CYCLE | STM32 自产自数 | STM32 捕获线上下降沿计数(首沿=1) |

对齐引擎不受影响: CYCLE 仍在数据帧里、PA1 沿时间戳仍是锚点、
相机 PTS 与 XVS 同源(cam0 就是源)→ 标定后 offset 更稳。

## 已知边界(记录, 不阻塞单手)

- **双手场景未闭环**: 从机手套的相机只能从 SBU 拿到 XVS、拿不到 XHS →
  从机手套相机启动不了(同一个 XHS 硬约束)。且若从机手套让自己的 cam0 也当
  master, 其 XVS 会与 SBU 上主机手套的 XVS 在共网上冲突。
  → 双手方案待下版板(XHS 过 SBU / 或从机手套 XVS 网与 SBU 可隔离)再设计。
- STM32 侧 50ms 宣告期间相机尚未启动, XVS 网空闲, 无驱动冲突;
  宣告结束必须先切输入捕获、再发 0xC301(保证 cam0 起振时 PB10 已是输入)。
