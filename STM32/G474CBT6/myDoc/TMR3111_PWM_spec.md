## 1. 芯片概述 ✅

- TMR3111 = **23 位 TMR（隧道磁阻）磁性绝对式旋转编码器**，封装 DFN10L (3×3×0.75mm)。
- 测量旋转**磁铁**的 0~360° 绝对角度（非接触）。
- 三种输出接口（可同时存在）：
  - **PWM**：12 位绝对角度，单线。← **本项目采用**
  - **SPI**：23 位绝对角度（MOSI/MISO/SCLK/CS）。
  - **ABZ**：增量正交输出，线数 1~4096 可编程。
- 内置 EEPROM，可掉电保存配置（零点/方向/分辨率等）。

### 关键电气/性能参数 ✅
| 参数 | 值 |
|------|-----|
| 供电 VDD | 3 ~ 5.5 V（典型 3.3/5V） |
| 工作电流 | 典型 10 mA，最大 ~23 mA |
| 角度范围 | 0 ~ 360° |
| 绝对分辨率 | 23 bit（SPI）；**PWM 为 12 bit** |
| 非线性误差(全温) | 典型 **±0.5°**，最大 ±0.65° |
| 重复性 | ±0.03° |
| 角度输出延时 | 2 µs |
| 最高转速 | 40000 RPM |

### 磁路要求 ✅（机械设计需注意）
- 推荐磁体：钕铁硼 (NdFeB)，**直径 6/9mm，厚度 2.5/3mm**，径向充磁（图示 S/N 对半）。
- 传感器与磁体安装气隙 Dz：推荐约 1~3mm。
- 中心轴偏移 ≤ 0.5mm，角度偏差 ±3°。
- 每个关节都需要一颗旋转磁铁正对芯片，这是机械结构的硬约束。

### 引脚（DFN10L）✅
| # | 名 | 方向 | 功能 |
|---|----|------|------|
| 1 | A | 输出 | A 相脉冲(增量) |
| 2 | MOSI | 输入 | SPI 数据入 |
| 3 | MISO | 输出 | SPI 数据出 |
| 4 | SCLK | 输入 | SPI 时钟 |
| 5 | CS | 输入 | SPI 片选 |
| 6 | VDD | 电源 | 电源 |
| **7** | **PWM** | **输出** | **PWM 角度输出** ← 本项目接 STM32 定时器输入捕获 |
| 8 | GND | 地 | 地 |
| 9 | Z | 输出 | Z 相(零位)脉冲 |

数字输出电平：VOH ≥ 0.8·VDD，VOL ≤ 0.2·VDD。**若 TMR 用 5V 供电，PWM 高电平≈5V，STM32 输入引脚需 5V 容忍或做分压/电平转换。** 建议 TMR 用 **3.3V 供电**与 STM32 同电平最省事（VDD 范围支持 3V）。⚠️ 确认供电电压。

## 2. PWM 输出编码（核心）✅

> 原文：PWM 占空比与磁场角度成比例，分辨率 12 位。一个周期 T = 1/F_PWM，含 **4119** 个最小时钟周期：以固定 **16** 个时钟高电平开始，**8** 个时钟低电平结束，中间 **4095** 个时钟为 12 位角度数据。频率由寄存器 `pwm_fre_sel[1:0]` 设定。

### PWM 帧结构（图 6）
```
|<--16 clk 固定高-->|<------ 4095 clk 角度数据 ------>|<--8 clk 固定低-->|
|        START      |  code ∈ [0,4095] 决定高电平时长   |       END        |
|<---------------------- 一个周期 = 4119 clk = 1/F_PWM ------------------->|
```

### F_PWM 可选（`pwm_fre_sel[1:0]`）✅
| 频率 | 周期 T | 最小时钟 t_clk = T/4119 |
|------|--------|------------------------|
| **1000 Hz（默认/典型）** | 1.000 ms | ≈ 242.8 ns |
| 500 Hz | 2.000 ms | ≈ 485.6 ns |
| 250 Hz | 4.000 ms | ≈ 971 ns |
| 125 Hz | 8.000 ms | ≈ 1.943 µs |

### 占空比 ↔ 角度 换算
设 `code` = 12 位角度值 ∈ [0, 4095]：

- **高电平时长** t_high = (16 + code) × t_clk
- **占空比** D = t_high / T = (16 + code) / 4119
- 反解：**code = round(D × 4119 − 16)**，并夹紧到 [0, 4095]
- **角度** θ = code / 4096 × 360°   （°/LSB ≈ 0.0879°）

> 校验：code=0 → 高=16 clk（D≈0.39%）；code=4095 → 高=4111 clk（D≈99.8%），余 8 clk 低。✅
> ⚠️ θ 分母用 4096（12 位满码 4096 级）还是 4095，需用已知角度实测标定确认；差异 < 0.1°。

## 3. STM32 测量方案分析

### 用定时器输入捕获测占空比
- 因为 **所有传感器 F_PWM 相同且固定**，周期 T 已知（或可一次性测得），实际只需测每路 **高电平时长 t_high**，再用上式反解角度。
- 单通道双边沿捕获：一个定时器通道，配置上升沿捕获（记 t_rise）+ 下降沿捕获（记 t_fall），t_high = t_fall − t_rise。可配合 DMA 写入缓冲区。
- ⚠️ 不要用 CubeMX 的 “PWM Input” 模式：它一路信号占用 **2 个通道 + 从模式复位**，每个定时器只能测 1 路 → 21 路要 21 个定时器，不够用。

### 资源估算（STM32G473VET6）
- 可用捕获通道：TIM1/2/3/4/5/8/20 各 4 通道 + TIM15(2) + TIM16(1) + TIM17(1) ≈ **32 通道**。
- **21 路可行**：约需 6 个 4 通道定时器（如 TIM1/2/3/4/5/8 各取 3~4 通道）。
- 精度：1kHz 时 1 角度 LSB ≈ 243ns；STM32 定时器 170MHz（tick 5.88ns）→ 每 LSB ≈ 41 个 tick，足以分辨满 12 位。
- 定时器计数器位宽：TIM2/TIM5 为 32 位最稳；16 位定时器(如 TIM3/4)在 170MHz 下 1kHz 周期需注意分频，使一个周期计数 < 65535（例如分频到 ~50MHz：1ms→50000 计数，OK，分辨率仍 20ns/tick 足够）。

### 性能上限
- 更新率 ≤ F_PWM（1kHz 默认 → 每路 1ms 更新一次，延时 ~1ms + 内部 2µs）。
- 有效精度受非线性 ±0.5° 限制，PWM 12 位（0.088°）已优于器件精度，瓶颈在器件本身。

## 4. 待确认清单

1. ⚠️ TMR3111 **供电电压**（3.3V 还是 5V）——决定 PWM 电平是否需要电平转换到 STM32。强烈建议 3.3V。
2. ⚠️ **F_PWM 选择**：默认 1kHz（更新最快、延时最低），除非有抗噪/走线考虑才降频。
3. ⚠️ 角度换算分母 4096 vs 4095（实测标定）。
4. ⚠️ 21 路 PWM 引脚的**定时器/通道/引脚分配**（需在 CubeMX 里规划，避免与 6×UART/SPI1 引脚冲突）。
5. ⚠️ 各关节**零点**如何标定：可写 TMR 内置 EEPROM 零点，或在 STM32 端做软件零点偏移。
6. ⚠️ 是否需要多圈/方向信息（PWM 只给单圈 0~360° 绝对角；关节一般 < 360°，应足够）。
