# STM32 侧固件(STM32G474)

> 待推送。本目录用于放手套 MCU 侧的完整工程。

## 职责(与 RV1126B 侧的分工)

STM32G474 = **传感器主控 + SPI 从机 + XVS 时基**:

- 采集 5 路 CAN 节点(关节/触觉)+ I2C IMU,每个 XVS 周期打包成一帧;
- 作为 **SPI 从机**响应 RV1126B 的读取(恒定 2690 字节全双工事务);
- 产生/捕获 **XVS** 60Hz 时基,维护 **CYCLE 周期号**(全系统对齐的钥匙);
- 用 **PA1** 告知 RV「有新包可读」。

## 关键约定摘要

| 项 | 值 |
|---|---|
| SPI | Mode 0 / MSB / 硬件 NSS / 恒定 1345 字(2690 字节)全双工 |
| 事务间隔 | 相邻两次 ≥100µs(DMA 重装窗口) |
| PA1 | 高=有包;运行态在 XVS 后 3~8ms 拉高,保持到下个 XVS |
| XVS | 60.000Hz,低有效,低脉宽 7.25µs(=1H),**下降沿=帧基准** |
| XHS | ⚠ IMX415 从机**启动**必须同时收到 XHS(1H 周期行同步);详见 RV1126B/README.md 的已知硬约束 |
| CYCLE | 首个 XVS 下降沿=1,暂停照涨不清零 |
